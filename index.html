Comment ça marche ?

    
1. Câbler

    
    
      
  • Clique sur un composant à gauche pour le poser, ou fais-le glisser sur le plan.
    • 
      
  • Pour tirer un fil : clique sur une borne (petit rond), puis sur une autre borne. Survole une borne pour voir son nom.
    • 
      
  • Un fil partant du 5 V est rouge, un fil partant de GND est noir. Le rond coloré en haut à droite choisit la couleur des autres fils.
    • 
      
  • Clique sur un composant ou un fil pour le sélectionner : Suppr l’efface, R fait pivoter un composant.
    • 
      
  • La barrette de connexion relie tous ses trous entre eux : pratique pour partager le GND ou le 5 V.
    • 
      
  • Breadboard : pose un composant sur la plaque, ses pattes s’enfoncent dans les trous. Les 5 trous d’une colonne (a–e ou f–j) sont reliés, chaque rail + ou − est relié sur toute sa longueur. Survole un trou pour surligner ce qui lui est relié.
    • 
    

    
2. Programmer

    
    
      
  • Blocs : glisse les blocs dans « Au démarrage » (setup) ou « Répéter sans fin » (loop). Un simple clic sur un bloc l’ajoute à la fin. Pour supprimer un bloc, ramène-le dans la palette.
    • 
      
  • Code C : écris le programme comme dans l’IDE Arduino. « Modifier en C » recopie le code des blocs pour continuer à la main.
    • 
      
  • La carte exécute l’onglet sélectionné (Blocs ou Code C).
    • 
    

    
3. Tester

    
    
      
  • ▶ Téléverser lance la simulation. Appuie sur les boutons, tourne les potentiomètres, règle la lumière ou la température du capteur sélectionné.
    • 
      
  • Pendant la simulation, survole une borne pour mesurer sa tension, ou sélectionne une LED pour voir son courant : c’est ton multimètre.
    • 
      
  • Une LED sans résistance grille, une entrée « en l’air » donne des valeurs au hasard, un court-circuit coupe l’alimentation : comme en vrai.
    • 
      
  • Vérifier le défi teste automatiquement ton montage et ton programme.
    •
